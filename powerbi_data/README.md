# Power BI data marts

Ці дев’ять CSV є фінальними невеликими вітринами, які створює останній блок `case3_antifraud.ipynb`.

Вони включені до репозиторію, щоб Power BI dashboard можна було відкрити та перевірити без повторного розрахунку 1.4 ГіБ Parquet.

Після **Run All** ноутбук перезапише ці файли тим самим форматом.
